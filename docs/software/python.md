
Install Python following the instructions below.

=== "Windows"

    1. Go to [python.org/downloads](https://www.python.org/downloads/) and download Python.
    2. Run the installer. On the first screen, check “Add python.exe to PATH”, then click Install Now.
    3. Open Command Prompt and verify:
        ```
        python --version
        ```


=== "macOS"

    1. Go to [python.org/downloads](https://www.python.org/downloads/) and download the latest macOS installer (.pkg).
    2. Open it and follow the prompts.
    3. Open Terminal and verify:
        ```
        python --version
        ```
    
    Alternatively, install Python with Homebrew:
    ```
    brew install python
    ```
